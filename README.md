# Northstar Retail — SQL Business Operations Simulation

A job-style SQL project simulating the day-to-day responsibilities of a
Junior SQL Analyst / Database Support Analyst working with an existing
e-commerce database.

## Project Overview

Northstar Retail is a fictional Canadian e-commerce company selling
electronics, accessories, home-office equipment, and consumer products.

The project simulates working with an existing operational database and
responding to business requests from departments such as Sales, Finance,
Operations, Customer Support, and Management.

The focus is not simply writing SQL queries, but translating business
requirements into SQL, investigating data, validating results,
troubleshooting issues, and considering query performance.

## Database

The NorthstarRetail database currently contains:

- Customers
- Orders
- OrderItems
- Products
- Categories
- Suppliers
- Employees
- Payments
- Shipments
- Inventory

The simulation contains approximately:

- 1,000 customers
- 5,000 orders
- 13,000 order items
- 5,000 payments
- 5,000 shipments
- 200 products
- 400 inventory records
